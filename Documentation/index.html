Welcome to METRO.SaaS premium React admin dashboard template dashboard. This documentation helps you configure and run the project infrastructure seamlessly.

🚀 Quick Start (Installation)

Follow these quick commands inside your terminal to initiate the development environment:

# 1. Extract the project and open the root directory
cd ilksablonum

# 2. Install all core & framework dependencies
npm install

# 3. Launch the local live development cluster
npm run dev

📦 Features Integrated

  • State Persistence: Full CRUD simulator synced natively with browser localStorage.
  • Data Visualization: Powered by Chart.js (Line, Bar, and Doughnut architectures).
  • Data Exporting: Native corporate-aligned Excel/CSV extraction engine.
  • Theme Controller: Dual-layer Dark and Light ambiance layout.

🛠️ Tech Stack

  • React 19 (Functional Component Hooks)
  • Vite Bundler Grid
  • Tailwind CSS v4 Layouts
  • Lucide React Vektor Icons
